# Project instructions

- Keep the research dossier in `research-dossier/` current whenever research is carried out for this project. Archive core sources relied on before reporting completion, without needing a separate user request.
- Follow `research-dossier/00 - Start Here/Research guide.md` for filing, provenance, source registration and evidence gaps. Preserve original documents; keep analysis and assumptions separate.
- For site searches, use `research-dossier/06 - Our Analysis & Your Project/Site search commission/Master site-search prompt.txt` and the latest user instructions. The current search has a £2m purchase-price ceiling, no rent ceiling and no development-budget filter; do not apply the earlier £1.5m funding assumption as an exclusion.
- Record inaccessible sources honestly. A URL alone is not an archived source. Do not bypass access controls or invent missing source content.
- Do not use Canvas for dedicated deliverables. Keep work in the chat or local files; use HTML only when needed to illustrate findings. Canvas may only support an explanation or questions and answers within the chat.
- Do not call Firecrawl unless explicitly scraping websites for research data primarily used in web design.
- Do not contact third parties, publish, or upload this research without the user's instruction.
